在现有 mesh 骨架上，把它做成一个能把坏网格修好的解析与重建工具。保留 Vec3、Mesh、parse_obj、
triangulate、compute_normals、write_obj 的现有名字与签名，只用 Python 标准库，不得引入第三方依赖，
不得改动 data/model.obj。

## 需要完成

1. **索引语义**
   - 正负索引都要按 OBJ 规范解析，负索引指向从末尾数起的位置。
   - 索引越界要能报出具体面的行号，不能静默跳过。

2. **多边形拆分**
   - 四边形与更多边的面都要拆成三角形，凹多边形也不能拆出网格外的三角形。
   - 拆分后三角形总数与面数要能对上，判据写进 README。

3. **法线**
   - 顶点法线必须是单位向量，长度误差不超过 1e-6。
   - 面积大的面权重更高，法线方向要能反映这一点。
   - 绕序不一致的面不能把法线抵消掉，处理方式写进 README。

4. **重复顶点**
   - 位置完全相同的顶点要合并，合并后索引引用同步更新。
   - 合并前后网格外形不能变化。

5. **输出**
   - 产出 OBJ 文件，能被 `parse_obj` 重新读回且顶点数、三角形数与报告一致。
   - 连续跑两次输出逐字节相同。

6. **测试**
   - 覆盖：负索引解析、四边形拆分数量、法线单位长度、重复顶点合并、读回一致。
   - `python -m pytest tests -q` 全部通过。

完成后跑一遍 `python -m mesh.cli data/model.obj --out out.obj`，把顶点数、三角形数、合并掉的重复
顶点数、法线长度最大值与最小值贴进 README。
