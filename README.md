# OBJ 解析与法线重建

骨架能读顶点、能按面累加法线，但产出的网格是坏的。

## 已知缺口

- `parse_obj` 把负索引原样保留，`-4 -3 -2 -1` 这种面在后续 `face[i] - 1` 会变成负数下标，
  实际指向数组末尾的错误顶点。
- `triangulate` 只接受三顶点面，测试模型里 6 个面全是四边形，三角化结果是 0。
- 四边形没有做扇形或蝶形拆分，也没有处理凹多边形。
- `compute_normals` 累加后不归一，法线长度随相邻面面积变化，光照会过曝。
- 没有统一绕序，四面体混着顺时针与逆时针的面时法线朝向互相抵消。
- 重复顶点不合并，同一位置出现多次会让法线在各个副本上分摊。

## 运行

```
python gen_samples.py
python -m mesh.cli data/model.obj --out out.obj
python -m pytest tests -q
```

`model.obj` 是 8 顶点、6 个四边形面的立方体，第 2 个面用负索引写。
