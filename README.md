# OBJ 解析与法线重建

把坏网格修好的解析与重建工具：解析 OBJ（含负索引）、合并重复顶点、统一绕序、
面积加权单位法线、多边形（含凹多边形）三角化，最后写出可被自身重新读回的 OBJ。
只依赖 Python 标准库。

## 处理流水线

`parse_obj` → `merge_duplicate_vertices` → `compute_normals`（内部统一绕序）
→ `triangulate` → `write_obj`

### 索引语义

- 正索引为 1 基；负索引按 OBJ 规范折算：`-1` 指向当前已读入的最后一个顶点，
  `-k` 指向倒数第 k 个。解析后 `mesh.faces` 中全部是 1 基正索引。
- 索引为 0 或越界（正负都算）时抛出 `ValueError`，消息中带出错面所在的行号，
  不静默跳过。

### 多边形拆分

- 三角形原样保留；四边形及更多边的面用**耳切法**拆分：把多边形投影到法线
  最大分量垂直的平面上做二维耳切，因此凹多边形也不会拆出网格外的三角形。
- 数量判据：**三角形总数 == Σ(每个面的顶点数 − 2)**。退化多边形（共线、
  自交等找不到耳朵时）退化为扇形拆分，保证该等式仍然成立。
- 测试里用凹五边形验证面积守恒：拆出的三角形面积之和等于原多边形面积。

### 法线

- 顶点法线为单位向量，长度误差 ≤ 1e-6。
- 面积加权：按 Newell 法线累加，Newell 法线的模长正比于面面积，大面权重
  自然更高，无需额外加权系数。
- 绕序统一：先沿共享边 BFS，把与邻接面沿共享边走向相同（即绕序冲突）的面
  整体翻转，避免相邻面法线互相抵消；再按有向体积判断整体朝向，体积为负时
  把所有面再翻一次，使封闭网格的法线朝外。

### 重复顶点

- 位置 `(x, y, z)` 完全相同的顶点合并到首次出现的副本，面索引同步重写。
- 只做精确判等、不移动任何顶点，合并前后网格外形不变。

### 输出

- 写出的 OBJ 只含 `v` / `vn` / `f i//i` 行，能被 `parse_obj` 重新读回，
  读回后的顶点数、三角形数与运行报告一致。
- 输出无时间戳、无随机性，连续跑两次逐字节相同。

## 运行

```
python gen_samples.py
python -m mesh.cli data/model.obj --out out.obj
python -m pytest tests -q
```

`model.obj` 是 8 顶点、6 个四边形面的立方体，第 2 个面用负索引写。

## 实测结果（data/model.obj）

```
顶点 8，三角形 12，合并重复顶点 0
法线长度 min 1.000000000，max 1.000000000
```

- 顶点数：8
- 三角形数：12（6 个四边形 × 每个 2 个，符合 Σ(n−2)）
- 合并掉的重复顶点数：0
- 法线长度最小值：1.000000000
- 法线长度最大值：1.000000000
- 连续两次运行 `out.obj` 逐字节相同
